# Hamlet — หมู่บ้านยุคกลาง

เกมสร้างหมู่บ้านยุคกลางแบบ 3D แนว Foundation เล่นบนเบราว์เซอร์ (Safari/Chrome) ไม่ต้องติดตั้งอะไรเพิ่ม และเล่นแบบออฟไลน์ได้

## วิธีเล่น

```bash
cd ~/Documents/Hamlet && ./serve.sh
```

เปิด http://localhost:8080 ใน Safari หรือ Chrome

เล่นจาก Mac เครื่องอื่นผ่าน Tailscale: บน Mac mini รัน `BIND=100.64.194.122 ./serve.sh` แล้วเปิด http://100.64.194.122:8080

เกมบันทึกอัตโนมัติในเบราว์เซอร์ทุก 30 วินาที (เซฟแยกตามเบราว์เซอร์และเครื่อง)

## วิธีเล่นแบบย่อ

คู่มือฉบับเต็มอยู่ในเกม: ปุ่ม ☰ มุมขวาบน → 📖 วิธีเล่น (มี 8 หัวข้อ: เริ่มต้น, การควบคุม, การสร้าง, ทรัพยากร, ชาวบ้าน, ระดับบ้าน, มหาวิหาร, เคล็ดลับ)

1. **ระบายโซนที่อยู่อาศัย** ใกล้ศาลากลาง — ชาวบ้านสร้างบ้านเอง
2. วาง **คนเก็บของป่า** 2 หลังใกล้พุ่มเบอร์รี่, **คนตัดไม้** ติดป่า, **เหมืองหิน** ใกล้ก้อนหิน
3. เร่งเวลา 3× — ถ้าชาวบ้านมีความสุข (≥ 50%) มีอาหาร และคนไร้บ้านไม่เกิน 6 คน จะมีคนย้ายเข้ามาทุกเที่ยงคืน
4. ประชากร 6 → **โบสถ์**, 8 → **โรงเลื่อย**, 12 → **ฟาร์ม/โรงสี/ร้านขนมปัง**, 20 → **โรงเตี๊ยม**, 25 → **มหาวิหาร**
5. บ้านอัปเกรด 4 ระดับเมื่อได้รับความต้องการครบ (อาหาร → ศาสนา → ขนมปัง + บันเทิง → มหาวิหาร) และมีไม้แปรรูป/หินในโกดัง
6. ไม่ต้องสร้างถนน — ทางที่เดินบ่อยกลายเป็นทางดินเองและเดินเร็วขึ้น

## การควบคุม

| | |
|---|---|
| เลื่อนกล้อง | WASD / ลูกศร / ลากเมาส์ซ้าย (ตอนไม่ได้ถือเครื่องมือ) |
| หมุนกล้อง | Q / E / ลากเมาส์ขวา |
| ซูม | ล้อเมาส์ |
| หมุนอาคาร | R หรือ Shift + ล้อเมาส์ |
| ขนาดแปรงโซน | `[` `]` |
| ยกเลิก | Esc / คลิกขวา |
| หยุด / ความเร็ว | Space / 1 2 3 |
